
# Web Servers / Web Apps

Parts of web addresses ("URLs", "URIs")

<https://course.ccs.neu.edu/cs1800/schedule.html>

- Protocol: https
- Host: course.ccs.neu.edu
- Path: /cs1800/schedule.html
- Base path: /cs1800
- Base URL: <https://course.ccs.neu.edu/cs1800>

The traditional web (think ~1994):

- A web page is an HTML file (+ images maybe).
- A web site is a collection of web pages under
  some shared base URL.

- Web sites are served by a static web server program
  - On the computer serving the web site, the files for
    the site live in some directory, called the document root.
  - The server program is configured with that document root.
  - It gets HTTP GET requests, which include a path.
  - It finds the file with that path inside the document root,
    reads it, and sends it.
- Web sites are viewed by web browsers.
  - Allow the user to enter an address.
  - Make HTTP requests to servers to get HTML documents.
  - Parse and display those documents.
  - Handle clicking links.

For early HTTP, there was one more major feature: form submissions

- A page include some sort of form
  - e.g. Payment info has two fields: credit-card-num, expr-date
- Once the form is filled in, hit submit.
- This sends an HTTP POST request to the server.
- The server software needs to forward this to a custom program to
  handle the form submission.
- Form submission could include uploading a file.

Usefully, HTTP and HTML are standards.

- That means we don't need to use either a browser or a static
  web server.
- We can replace the browser with a custom HTTP client.
- We can replace the server with a custom HTTP server.

Custom HTTP servers.

- Static servers:
  - Take an incoming request, including a path.
  - Read a file from disk at that path.
  - Send the file
- But our custom server can instead do any arbitrary function
  with the same form.
  - Input: A path string
  - Output: An HTTP response
    - Content-type: text/html, or image/jpeg, or anything.
    - Body: Whatever bytes of data we want

When we get fancy with this, we've successfully built a Web Application
