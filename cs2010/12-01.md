### Careers

What do average people end up doing 6 months after they graduate with
a given major?

The bad news:

- Nearly half of all graduates don't end up immediately getting a
  job related to their major.
  - Case 1: Underemployment
    - A job that requires "a college degree"
    - A job that doesn't require any degree
  - Case 2: Looking for any job

## CS

- 70%: Programmer
  - Internal software developer
  - Public web services
  - Commercial software that users download
- Other common jobs:
  - Data analyst
  - System admin
  - IT Support
  - Quality Assurance (software testing)

Recommendation: Do more computer programming, do some personal
projects in your own time.

## IT

- 20%: Sysadmin / DB Admin / Network admin
- 20%: Tech Support / Help Desk
- 15%: Business / System Anayst
  - These go first to people with more business courses
- Other common jobs:
  - Software developer
  - Cybersecurity analyst
  - Technical sales

Recommedation: Build a homelab

## Robotics

- 20%: Software develper, not robotics
- 20%: Software develper, working on robots
- 20%: Robotics engineer / technician
- ... Test engineer

Recommendation: Take more programming classes. Run robots
in simulation.

## Math

- 25%: Software Developer
- 15%: Data analyst
- 15%: Math Teacher
- Other:
  - Actuarial analyst
  - Financial analyst
  - Business analyst

Recommendations: Explicitly consider grad school. Consider taking
some extra programming classes.
