
## Networking and Stuff

### The Internet

- A network of networks, connecting computers together globally
- A network is a means of communication between computers

### The World Wide Web

- The stuff on the internet that you can access with a web browser.

Stuff on the internet that isn't nessisarily the WWW:

- Phone apps (that aren't hiding a web browser).

### How the Internet Works

Loading google.com in a web browser:

- Type in the (text) address, press enter.
- Browser translates text address into numeric address,
  using DNS.
- Google.com => 192.178.155.100
  - All of those address portions are less than 256, so
    they each can be stored in 8 bits.
  - IPv4 network address (or IP address) is 4 bytes = 32 bits
  - There are only about 4 billion IPv4 addresses.
- Google.com => 2607:f8b0:4004:c23:0000:0000:0000:8a
  - An IPv6 address is 128 bits
  - IPv6 was standardized last century
  - Comcast had adopted it for residential users by 2008
- Once we have the address, we can send an IP packet to
  the Google web server.
- Complications with IP:
  - IP is unreliable. The internet sometimes delivers IP
    packets and it sometimes doesn't.
  - IP packets don't guarantee order.
- One IP protocol is TCP, which layers on top of IP to guarantee
  reliable delivery and ordering.
- TCP adds an extra layer of headers and a concept called port #.
- On top of TCP, we'll use the HTTP protocol to talk to a web
  server.

## What is an IP packet?

- A chunk of data, maybe 100 - 1500 bytes.
- Header: Source IP, Destination IP, Protocol #
- Body: Some bytes of data

## HTTPS: Secure Connection

Two properties:

- Server is autenticated
- Messages are encrypted

Mechanism here is public key encryption.

- Server has a public key, authenticated through the browser.
- They encrypt / sign things with their private key.
